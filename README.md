# HR Analytics Dashboard | Power BI

An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee data, workforce distribution, and attrition trends.


## Please preview the dashboard from the screenshots folder.


## Project Overview

Performed end-to-end data analysis and developed an interactive dashboard to explore employee demographics, workforce trends, and attrition patterns. Cleaned, transformed, and prepared raw employee data to generate meaningful insights through dynamic visualizations and department-level filtering.

## Key Features

- **Dynamic Department Filtering:** Explore data across Human Resources, Research & Development, and Sales.
- **KPI Cards:** Track total employees, attrition, attrition rate, average age, salary, and years at company.
- **Attrition Analysis:** Analyze attrition by gender, age, education, salary slab, job role, and tenure.
- **Interactive Visualizations:** Dynamically explore workforce metrics based on selected filters.
- **Workforce Insights:** Identify employee attrition patterns and potential retention trends.

## Data Analysis & Processing

- Performed data cleaning and preprocessing using Power Query.
- Handled data inconsistencies and prepared the dataset for analysis.
- Created calculated measures and KPIs using DAX.
- Analyzed employee demographics, salary distribution, and attrition patterns.
- Designed interactive charts, slicers, and visualizations for effective data exploration.
